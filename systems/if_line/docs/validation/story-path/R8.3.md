# R8.3 Validation - Legacy Route Removal Contract

## Scope

- Replaced route-family spot checks with one frozen authoring cutover matrix.
- Verified the runtime route table, generated OpenAPI, and checked-in OpenAPI
  snapshot against the same positive and negative operation sets.
- Removed an obsolete lifecycle test that mounted the unregistered Project and
  Release compatibility Routers directly.
- Kept stable Task, Asset, Voice, Media, ReadingSession, continuation, TTS, and
  image-service contracts outside the authoring removal set.

## Positive Contract

`tests/test_api_route_contracts.py` reads
`docs/api/story-path-authoring.openapi.yaml` as the frozen replacement
contract. Its 58 method-path operations must all exist in:

1. the FastAPI runtime route table;
2. `create_app(...).openapi()`; and
3. `backend/openapi.v2.json`.

This checks every Project, Bible, StoryPath, Outline, PathChapter, Candidate,
Script, Resource, VNGraph, atomic publication, and immutable public-read
operation instead of sampling one route family.

## Negative Contract

The removal matrix contains 49 legacy authoring/publication operations:

- Project status, claim, readiness, and old stats;
- project-wide Bible and Outline revisions/generation/activation;
- project plus `chapter_index` Chapter, Script, resource, and VNGraph routes;
- unversioned branch-candidate generation and lookup;
- split Release creation/withdrawal and mutable publication flags;
- public Release chapter reads keyed by display index; and
- the retired VNGraph assembly and chapter orchestration routes.

Every operation is absent from both dynamic and checked-in OpenAPI. Runtime
requests to the 48 fully removed paths return 404.

The removed `POST /api/projects/{project_id}/releases` operation returns 405,
not 404, because the frozen replacement contract intentionally retains
`GET /api/projects/{project_id}/releases` for immutable Release history. FastAPI
therefore recognizes the preserved path while rejecting the removed method.
The POST operation is absent from both OpenAPI documents; adding a hidden
tombstone handler solely to manufacture a 404 would re-register the removed
operation.

The canonical replacement Project collection is `/api/projects`. The trailing
slash variant is absent from OpenAPI; framework slash normalization is not an
authoring compatibility endpoint.

## Replaced Tests

`test_project_release_lifecycle_guard.py` mounted only old Router objects and
asserted removed mutable fields such as `is_draft`. Its remaining behavioral
intent is covered by:

- `test_project_state_projection.py` for ignoring legacy lifecycle flags;
- `test_atomic_publication_service.py` and
  `test_atomic_publication_lifecycle.py` for publish/supersede/rollback;
- `test_public_release_service.py` for active-Release-only public access and
  unpublish; and
- this removal matrix for the deleted `/publication` operation.

The duplicate chapter orchestration assertion was removed from
`test_removed_chapter_orchestration_routes.py`; its image-service and generic
asset-write bypass checks remain independent.
