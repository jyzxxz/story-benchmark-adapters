`StoryContextResolver.resolve` starts from one stable PathChapter ID, loads only
rows owned by that StoryPath, walks predecessor IDs, and freezes the currently
selected Bible, path Outline, state snapshot, and exact ancestor Chapter
Revisions. Ancestors are emitted oldest-first and the context hash is SHA-256
over canonical JSON.

`resolve_frozen` verifies the supplied hash and reloads the exact IDs without
consulting mutable Heads. Tests prove that later parent, sibling, Bible,
Outline, and Chapter Head changes cannot alter an already frozen task input.
Malformed cross-path predecessors, cycles, missing ancestor selections, and
revision-to-slot mismatches fail with stable application error codes.
