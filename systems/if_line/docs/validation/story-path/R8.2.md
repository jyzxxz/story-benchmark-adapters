# R8.2 Validation - Legacy Sequence-based Frontend Removal

## Scope

- Removed the frontend clients, pages, components, and route records that used
  project plus `chapter_index` as authoring identity.
- Kept `/project/:id` as the single authenticated StoryPath workspace.
- Migrated project statistics from the removed `/stats*` contract to
  `/metrics` and `/metrics/artifacts`.
- Preserved the public Three Kingdoms reader and its stable guest APIs.

## Removed Routes

The frontend Router no longer exposes these compatibility pages:

| Removed page | Replacement |
| --- | --- |
| `/project/:id/bible` | `/project/:id`, Story Bible tab |
| `/project/:id/outline` | `/project/:id`, StoryPath outline tab |
| `/project/:id/chapter/:chapterIndex` | `/project/:id?path={story_path_id}&chapter={path_chapter_id}` |
| `/project/:id/chapter/:chapterIndex/assets` | `/project/:id`, immutable Script resource workflow |
| `/project/:id/read/:chapterIndex` | immutable Release public projection |
| `/project/:id/vn-graph/:chapterIndex` | `/project/:id`, Script Revision VNGraph workflow |

`/project/:id/stats` remains available, but its data source and identity model
are replaced rather than adapted through a compatibility client.

## Removed Clients And UI

Removed compatibility API clients:

- `assetApi`, `chapterApi`, `chapterScriptAssetApi`, `projectApi`, and
  `releaseApi`;
- `revisionsApi`, `statsApi`, `visualAssetApi`, `voiceApi`, and `workflowApi`.

Removed the six route-only legacy views and their four revision/voice content
components. The VNGraph asset URL utility and its tests were also removed
because their only runtime consumer was the deleted sequence-based preview.
The old project-assets Playwright scenario was deleted with its unreachable
route.

`VisualNovelStage` now owns the small structural types needed to render public
manifest assets. It has no dependency on an authoring API adapter.

## Metrics Replacement

`StatsView` now requests both current StoryPath metric projections in parallel:

- `GET /api/projects/{project_id}/metrics` supplies StoryPath UUIDs,
  parent-path UUIDs, PathChapter UUID membership, revision counts, and task
  distributions.
- `GET /api/projects/{project_id}/metrics/artifacts` supplies GenerationTask,
  PathChapter, source Revision, AssetVersion, and StorageObject UUID links.

The response contracts are explicitly typed in `storyPathTypes.ts`. The page
does not reconstruct chapter identity from display order and does not call the
removed `/stats` or `/stats/breakdown` endpoints.

## Contract Guards

The frontend unit suite now asserts that:

- legacy client and sequence-based view source files do not exist;
- the active Router has no `chapterIndex` parameter or distributed authoring
  route; and
- the unified workspace and publication surfaces import only StoryPath clients.

The StoryPath Playwright suite also covers the metrics page with only the new
metric endpoints mocked. It verifies visible PathChapter and Revision UUIDs and
checks a 390 by 844 viewport for page-level horizontal overflow.
