# R4.2 Validation - ChapterScriptRevision As The VNGraph Skeleton

## Scope

- Made `ChapterScriptRevision.id` the required and only VNGraph compile source.
  Compilation no longer accepts ChapterRevision as a fallback, selects a latest
  Script, or creates a compatibility Script.
- Rekeyed VNGraph revision numbering to `(script_revision_id, revision_no)` and
  added a Script-scoped creation index. Equal display indexes on sibling paths
  now own independent graph histories beginning at revision 1.
- Made VNGraph Revision and Head Script source IDs non-null. Migration `0032`
  backfills both from exact existing pointers, removes the obsolete index-based
  uniqueness constraints, and permits an empty Head current pointer.
- Added exact Head discovery, Script-scoped history queries, optimistic Head
  activation, no-op re-selection, and stale-token rejection.
- Changed successful compilation to create a `ready` revision without moving
  the Head. The selected parent is captured at enqueue time rather than worker
  persistence time.
- Updated resource confirmation, the automatic resource-ready enqueue path,
  the Three Kingdoms seed, and the recompile utility to retain the exact Script
  source. The old index route remains only as a validating adapter until R8.
- Kept the current AssetVersion and VoiceLine snapshot representation intact.
  The fully versioned immutable binding manifest is the separate R4.3 scope.

## Coupling Audit

- **Script:** only the exact immutable Script UUID identifies a graph family.
- **Chapter and StoryPath:** ChapterRevision and display index are derived
  provenance; equal display positions cannot merge sibling graph histories.
- **Resources:** resource confirmation carries the base graph's Script UUID
  into each child revision and updates only that Script's Head.
- **Tasks:** Script, Chapter hashes, compiler versions, selected parent, and the
  current resource snapshots are captured before enqueue and revalidated by
  the worker.
- **Review:** compilation never activates a graph; only explicit Head CAS does.
- **Migration:** old pointers and lock versions are preserved while nullable
  source identities become mandatory.
- **Next item:** R4.3 replaces mutable VoiceLine input with VoiceLineVersion and
  persists the complete immutable binding manifest on each graph revision.
