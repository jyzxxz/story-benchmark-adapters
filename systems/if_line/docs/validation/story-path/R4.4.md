# R4.4 Validation - Retired Index-Based VNGraph Assembly

## Scope

- Deleted `app/services/vn_graph_assembler.py` and
  `app/services/chapter_vngraph_assembly_service.py`. Neither module had an
  active production caller; both resolved mutable legacy rows through
  `(project_id, chapter_index)`.
- Removed the obsolete `PARALLEL_ASSET_BRANCHES` setting that only controlled
  automatic resource generation inside the retired assembler.
- Deleted tests whose subject was exclusively the retired implementation and
  removed its one helper-only case from the otherwise active visual Bible
  suite. Current resource-slot, immutable-manifest, compiler, and visual-action
  tests remain intact.
- Added an architecture test that requires both files to remain absent and
  rejects assembler class names, module names, and entrypoints anywhere under
  `backend/app`.
- Kept the indexed v2 URL adapter until R8. It requires an exact
  ChapterScriptRevision UUID and only verifies project/index presentation
  fields after UUID lookup; it cannot invoke or recreate legacy assembly.

## Coupling Audit

- **Script and graph:** graph construction starts only from an exact immutable
  ChapterScriptRevision. No fallback chooses a graph skeleton by display index.
- **Assets and voice:** Script resource slots, AssetBindings, AssetVersions, and
  VoiceLineVersions replace assembler-time scans of mutable legacy tables.
- **Workers:** `vngraph.compile` is the only production graph-construction task;
  it reconstructs one frozen manifest and never auto-generates missing media.
- **Routes:** the indexed compile URL remains a validating boundary adapter
  until R8; the old full-graph assembly routes are already absent and 404.
- **Agent:** no graph assembly tool is registered or discoverable.
- **Frontend:** old index-oriented client/view cleanup belongs to R6/R8 and is
  deliberately not mixed into this backend service retirement commit.
- **Historical material:** old Blueprint P3 and archival `Docs/learn` files are
  retained as history, not executable dependencies.
- **Next item:** R5.1 introduces the immutable publication readiness and
  authoring fingerprint calculator.
