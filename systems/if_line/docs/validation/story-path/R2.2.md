Bible generation tasks now freeze the selected parent Revision and a canonical
snapshot of all mutable project prompt inputs. Workers verify the snapshot hash
before any provider call. A corrupted source is rejected as non-retryable, and
editing the Project after enqueue cannot alter the task input.

Finalization always creates or resolves a complete, unselected Bible Revision.
It emits `review_required`, returns `activated: false`, and never changes the
Bible Head or its lock version. Explicit activation is the only selection
operation, advances the legacy workflow projection without rewinding later
stages, and is idempotent when the requested Revision is already selected.
