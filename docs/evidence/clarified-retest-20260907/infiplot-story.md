# infiplot 本轮新增正文

原文仅添加段落分隔与原生说话人标记；未修写故事。固定开头另存，不计入新增正文。

雨没有要停的意思，反而更密了，噼里啪啦砸在台阶上，溅起细碎的水花，洇湿了你的裤脚。冷蓝色的灯光从头顶斜斜压下来，把那扇紧闭的楼门照得发白，门楣上「实验楼」三个字掉了漆，剩下一半轮廓模糊地嵌在灰水泥里。

周遥还站在原地。他穿了件深色外套，肩膀已经被雨打湿了一大片，可他自己好像没注意到。他的视线从红伞移到门缝，又从门缝移回红伞，来来回回，像在确认什么，又像在躲着什么。

你：三次。间隔很短，不像雷声，也不像铁皮被风吹动。他昨晚真的来过这里？

你往前迈了半步，雨水顺着帽檐滴下来，落在鼻尖上，凉得人一激灵。

你：“周遥，你昨晚——是几点到这边的？”

他没有立刻回答。雨声在两人之间横亘了几秒，他才慢慢转过头来，眼里的神色像是刚从水里捞出来似的，湿漉漉的，又有些发直。

周遥：“我不知道。我只记得……雨很大，我撑了伞。然后我就——”

他顿住了，喉头动了一下，没再说下去。那把红伞就靠在门边，伞尖抵着门槛，伞面上积了一层薄薄的雨水，顺着伞骨往下滴，在水泥地上洇开一小滩暗色。

你：他说他撑了伞。可那把伞，是红的。他平时用的伞，是黑的。

这个念头冒出来，你下意识又看了那把红伞一眼。伞柄朝外，像有人走的时候随手一放，又像是特意摆成这个角度，好让从台阶下的人一抬眼就能看见。

周遥忽然往台阶上迈了一步。你伸手，搭住他的胳膊。

你：“先别上去。”

他停住，回头看你。灯光在他脸上投下一半明一半暗的光影，他的嘴角动了动，像是想说没事，可最终什么也没说出来。

楼里又传来一声电流的杂音，断断续续，像老旧收音机在调频时发出的那种沙沙声。紧接着，又是三次短促的信号——滴，滴，滴。间隔均匀得像用尺子量过。

周遥的肩膀微微一颤。你感觉到他手臂上的肌肉绷紧了，隔着湿透的布料，硬得像石头。

周遥：“你听到了吧。”

他问得很轻，像怕惊动什么似的。声音落下，雨声又灌了进来，密密麻麻地填满台阶前的每一寸空隙。

你：那个信号，真的不像巧合。可周遥现在的样子……比那扇门更让我不放心。

红色的伞尖在灯光下泛着湿润的光，雨水顺着伞面滑落，在地上砸出一朵又一朵转瞬即逝的水花。门缝里透出一线极暗的光，像有什么东西在楼里醒着，正等着人推门进去。

周遥偏过头，看着你搭在他胳膊上的手，声音哑哑的。

周遥：“林澈，你说……我要是不进去，是不是就永远想不起来了？”
