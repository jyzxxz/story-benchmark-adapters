本次验证对应三个独立批量入口、共同阅读窗口与八项指标证据采集。原生源码未修改；必要的外置输入、运行、鉴权测试环境和观测规则分别公开在三个 `native_shims` 目录的说明中。

## 工程验收口径

本地固定响应服务用于检验原生流程、图片接口、真实播放器、选择及证据关联，不用于证明模型质量。真实模型运行另列，保留所有原生失败；不会为了得到好故事自动重跑。

基线完整性检查覆盖 IF Line 1200、AI4VisualNovel 35、InfiPlot 927 个发布文件，共 2162 个文件，均须与 `baseline-lock.json` 一致。公共输入除编译判等，还检查真实接收端和首次创作请求。

公共回归覆盖句界与 Unicode 计数、真实 usage 缺失、请求中断、图片候选与资产区分、签名链接脱敏、正文来源、菜单/占位帧计时、进程独占、冻结任务、拒绝错误样本与计划混用。调度并发与生成条件分开记录。

三者实际接收文本、首次创作请求中的公共任务、模型配置、样本身份及适配器版本均一致；比较器输出 `actual_received_inputs_identical=true`、`integrity_valid=true`、`comparison_ready=true`。该结果允许将成功和失败证据一起进入后续评审，不表示三份内容都完整或质量通过。声明的批次并发和主机配置一致，其他主机负载及供应商限流未作同等性证明。

三个根运行共核对 3983 个证据文件（IF 3260、AI4 94、Infi 629），指标均可重算。2162 个原生发布文件仍与源码锁一致；1108 个保存的文本证据文件未发现本次真实供应商密钥值。原始图像、实际路径和失败证据保存在独立本地档案，不提交到 Git 源码仓库。

已核实的原生停止原因：

- AI4VisualNovel：模型输出 `root + node1…node10` 共 11 个节点，原 `agents/designer_agent.py:115–118` 要求 12 个，直接抛错；未到 `workflow.py:257` 的故事图审核循环。8 次文字请求全部完整 HTTP 200，用量为 29,428 输入、9,257 输出，合计 38,685。没有正文、图片或实际选择，不能评价内容质量。单个样本不足以确定公共提示词对模型出错概率的影响。
- InfiPlot：原 `lib/ai-client/image.ts:220–224` 将供应商返回的图片 base64 作为 data URI；原页面继续把包含历史图片的 Session 发送到 `/api/scene`。请求达到约 11.53 MB，触发原 Next middleware 的默认 10 MiB 请求体限制；被截断后，原 `app/api/scene/route.ts:28–30` 返回 400 `Invalid JSON`。实际保留 3007 字、56 对画面、2 次已提交选择；第三次仅点击意图，未提交。供应商 20 次请求均完整成功，文字 65,744 tokens、图片 26,561 tokens。此处的框架请求体上限与适配器 token/费用预算分别记录。

两者输入均逐字一致并完整进入首次创作请求，源码与适配器运行期间均未变化。原生失败原样保留；没有补节点、改错误输出、删 Session 图片或提高原生框架上限来掩盖结果。AI4 94 个文件、Infi 629 个文件的封存及指标重算均通过；AI4 正文来源标记为 `not_applicable_no_body`，Infi 为 `passed`。
