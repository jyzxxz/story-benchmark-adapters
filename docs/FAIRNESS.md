# 公平性边界与验收

本仓库要建立的条件是：相同外部任务和固定开头，经过各自原生方法，产生可追溯的结果。不会保证哪个项目质量更好，也不会为了得到差异而修改故事。

## 输入三层检查

1. 编译层：唯一公共文本与三个载荷逐字比较，长度与 SHA-256 留档。
2. 接入层：记录实际读入的需求或任务快照；外部网关和 SDK 边界的观察会明确标注，不能冒充原生路由内部记录。
3. 发送层：捕获实际模型发送请求；首个消费共同任务的请求必须完整包含共同区块一次。首次正文及后续请求保留实际传播情况。

共同开头存在于 `shared_task.txt`，不在 IF Line 的 `story_start` 再重复一次；也不通过伪造 InfiPlot history/storyState 或额外 AI4VisualNovel OC 来加强某一方。

## 原生方法保留

保留各自规划、记忆、人物处理、审核、原生修复和输出 schema。后续原生流程使用摘要、遗漏开头或写出矛盾，都保留为系统表现；适配器不得在每轮再次注入固定开头以修复它。选择哪个原生入口和怎样初始化公共前文必须公开记录。

外置规则仅替换与“已有固定开头”直接冲突的入口假设，并安装只读证据采集和显式预算控制。它们属于实验适配行为，源码目录保持原样不是“完全未经适配的运行”的证明。

IF Line 的 Bible 基础输入渲染由外置包装替换；AI4VisualNovel 经原生需求入口并保留设计到全图脚本的步骤；InfiPlot 通过原生模型 endpoint 配置接入外部 relay，仅按冻结版本精确替换冷开场句。匹配失败必须拒绝或报告，不做模糊优化。

新版 `CAMPUS-01-C1` 使用 IF Line 的显式 `provided_prefix_candidates` 接入模式：Bible 和大纲之后，把公共固定开头逐字作为人工提供的章节修订，使用原生 API 创建并激活。外置初始化接口补上原生未提供创建入口的 checkpoint 结构，并调用原生服务保存空状态 `{}`；只记录 ID、来源和哈希，不从剧情提取额外记忆。随后调用原生候选分支生成接口，机械映射公共 `decisions[0]` 与行动顺序原文到它的 instructions 字段。没有新增故事信息，但这确实改变了 IF Line 的启动接入方式和公共信息出现的位置，不能称为“内部完整请求也相同”或未经适配的默认工作流。

这次初始化只发生一次，不先生成错误开篇再覆盖，不写人造选项标题，也不选择、晋升或执行任何候选。原生候选是选择之后的正文预览，放入 `unselected_previews.jsonl`，不计作当前路径正文，不满足“选择前衔接正文＋两个选项标题”的公共输出边界。源文件零改动和这个能力限制同时如实记录。

## 统一模型与预算

`experiment.example.json` 只设置一份共同条件，不允许三个系统分别选择更强模型或更大预算。实际请求模型与供应商返回的模型名称分别记录，别名与版本差异不能静默忽略。

共同 `model_parameters` 只控制显式冻结的推理模式，不允许附加故事说明或改写原生 JSON schema；每次实际 HTTP 请求都必须匹配已配置的参数。

预算口径：一个系统的一次根运行包含全部规划、正文、审核、失败重试；限制实际 HTTP 发送次数、单次输出 token 上限和单次紧凑 JSON 请求的 Unicode 码点数。缺失输出上限时设置共同上限，已有更低的原生上限则保留。限制条件和实际采样参数均记录。

这是一种可执行的请求预算，**不等于严格等金额或等 token 消耗**。金额未知为 null；缺失 usage 为 null，失败重试或流不完整会降低覆盖状态。SDK 与 HTTP 两层记录不能重复计费。原生算法在预算耗尽后返回兜底内容时，应标预算中断或 degraded。

原生角色数量和图大小可能形成额外约束，例如 AI4VisualNovel 的角色数量包含主角，其原生全图节点数不是每条路线场景数。参数含义及原生默认差异必须随实验冻结；不能仅凭数值相同就宣称约束相同。

IF Line 的规划章数采用原生界面默认 13。旧 `first_chapter` 模式只生成首章；新 `provided_prefix_candidates` 模式导入公共前文后生成两个未选择候选。章数 1 会要求全书在该章完结，不能用来控制首批导出范围。原生 worker 多次创建事件循环却缓存异步模型客户端，外置 HTTP 连接层禁用异步 keepalive，避免跨循环复用连接；原生 SDK 重试策略保留。传输异常仍记录为交付未知，不能当成未发出或零用量。

## 输出与状态

公共开头单独放在 `provided_prefix.txt`，不计系统新增正文。正文及说话人按原生格式提取，每段有 source pointer；不删除重写开头或矛盾段落，不使用内部 summary/memory 补正文。AI4VisualNovel 按原生播放器语义执行无条件 jump，InfiPlot 遍历 continue 边；均在首个选择前停下。遇到未支持的条件控制时停止，不拼接互斥内容。

输入正确但生成故事违反要求，与接入失败是不同状态。完整接入需要真实入口与发送证据，payload 判等不能代替；mock 供应商工程测试不能称为真实模型故事实验。

本阶段没有播放器分支可达性证明，报告不会设置 `player_reachable=true`。
