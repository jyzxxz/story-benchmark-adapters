# 当前图文实验的公平性边界

当前主入口为 `experiment.sh`，默认使用开放式 30 题：同一份任务与固定开头、共同模型条件、共同阅读范围和证据格式，各项目按自己的原生方法发展故事。操作见 [生成者交接手册](OPERATOR_HANDOFF.md)，逐字段采集见 [八项记录](BATCH_RECORDING.md)。

## 输入和创作方法

每题只编译一份 `shared_task.txt`，三项目接收相同公共文本；编译和接收检查保留原文、哈希及实际入口记录。不能分别补写人物、开头、未来行动或故事答案。后续模型请求由各系统原生规划、记忆和审核组织，因此完整模型请求不要求逐字相同。共同输入相同不能单独证明剧情满足要求。

当前开放版不预设后续关键行动，也不强迫三个故事采取语义相同的路线。菜单策略使用原生下标并保留执行结果，不能把不同项目的“第二项”解释成同一个剧情行动。选择、正文与画面按实际路径记录；未生成的路线不补写，也不拼入主路径。

## 原生来源和允许的接入

AI4VisualNovel 和 InfiPlot 保持冻结来源；IF Line 使用已明确授权并披露的 [HTML 转换修复](IFLINE_HTML_PATCH.md)。三者的来源锁、公开补丁及运行时适配记录见 [来源说明](PROVENANCE.md)。它们是公开说明了接入规则的实验运行方式，不能统称完全未经适配的上游默认部署。

原生规划、审核、重试、预取和输出结构继续保留。AI4 的节点数校验失败、原生图文问题或供应商错误均记录，不通过补节点、改故事、替图或删除失败来提高结果。InfiPlot 的冷开场接入和请求容量处理属于已披露外置规则，不能从中推断它已经具备原生完整结局。

## 共同观察范围

现行 v4 图文采集按共同新增可见字符窗口与句界规则停止，默认约 4000 字符。公共开头、内部规划、菜单和未选预览不计入新增正文。窗口内继续原生故事、执行规定的菜单策略并记录实际选择；**不再采用 v3 的“所有选择未执行、停在第一个选项”范围**。

观察窗口完成、原生结束、提前失败和采集缺失分开呈现。InfiPlot 没有固定全篇结束点也可参与相同范围评审，不仅因缺少完整结局而扣分；提前停止或缺失不能隐藏。固定开头是共同材料，不算某项目独有的生成贡献，但后文仍应与之相容。完整多分支可达性或整部作品交付不是当前窗口采集自动证明的事项。

## 模型、消耗和等待时间

文字、图片和原生视觉审核分别使用共同配置；图片模型为 `gpt-image-2`。冻结模型、端点、共同参数和输入，拒绝各系统另设公共条件。适配器不设总调用、总 token、总费用或总生成时长上限；原生和供应商单请求、余额、限流等限制仍存在。

规划、审核、失败重试、预生成和未读预取都计入根运行的实际消耗。相同预算政策不等于相同费用；未知 usage 或费用保持未知，不估填零，也不重复累计同一次请求或复用资产。外部评审调用另记，不混入原生生成成本。

默认统一入口按系统顺序执行，在活跃系统内按根任务并发。等待时间结合调度、并发、主机和供应商限流信息解释。当前离屏观测不能称为真人桌面显示延迟；回放翻页时间和回放页数分别不能替代原等待时间和图片生成数量。

## 证据和评审

停止原生消费者、收集请求和产物后封存，保留正文—画面—资产—调用关系、输入、选择、错误、用量和完整文件哈希。未观测的字段保持未知；封存和结构校验不代表故事质量通过。

五类内容指标只准备评审材料，三类资源/时间指标来自真实记录。所有已封存样本可派生离线回放，失败/零正文样本一起保留。派生过程不重写故事、不重新计算八项指标。盲评者获得回放 ZIP，组织者保存原始证据和 ZIP 外的来源映射及指标。

固定响应 fixture 只验证工程链路；真实运行只证明报告中的案例、版本与范围。旧 v2/v3 的文本、首选择和限额测试见 [历史资料索引](README.md)，不能作为现行图文批量程序的运行说明或新机器验收结论。
