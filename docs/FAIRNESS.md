# 公平性边界

本实验统一外部任务、固定开头、返回结构与范围。各项目保留原生方法，故事文字可以不同。具体字段见 [v3 合同](V3_CONTRACT.md)。

## 输入检查

唯一 shared_task.txt 只在编译时规范化一次。编译器保存原始 brief、opening、prefix 字节和 case，重建文本检查实际载荷。接入时读取实际原生收件；首次创作模型请求必须完整包含共同文本一次，并记录真实边界。InfiPlot 的观察位于 SDK 消息，不冒充直接路由字段钩子。

公共人物名单是总名单，包括玩家；AI4 的 exact character_count 与公共文字含义一致。原始 brief 和开头不由各适配器分别改写。

后续模型请求依照各项目的原生规划和记忆组织。适配器不再补发剧情规则，不增添人设、大纲、记忆或结局，不补写或修复故事。是否遗忘开头、违背选择、写出矛盾是原生输出表现，单靠哈希不能判定语义正确。

## 外置接入

systems 中的每份发布文件与冻结基线逐字节相同；运行时接入包装全部公开在 benchmark 中，不能称为完全未经适配的默认运行。

IF Line 替换首个 Bible 入口的基础输入区块，原生生成 Bible 和 outline，再通过原生人工修订接口一次性导入公共开头。外置接口补建纯结构 checkpoint 和空状态 `{}`；不从故事提炼状态。原生候选请求省略 instructions，仅映射公共选择数，保留原生 option_key 与候选预览。native_context 保存依赖与来源，语义标记 not_evaluated。原生不存在合法的无 Bible/outline 候选入口；不能靠丢弃规划或调整初始化顺序冒充同一原生链。

AI4VisualNovel 通过原生需求入口，保留设计、全图规划、人物处理、Actor/Writer 和校验。节点数量、JSON 或其他原生失败保留，不跳过校验或补节点。导出依原生无条件 jump 前进，到首个未选择选项停止；不执行条件分支。

InfiPlot 使用原生 /api/start，外部 relay 仅按锁定文本替换与公共固定开头冲突的冷开场句，保留全部其它消息/schema。原生审核、角色心理规则和选择后种子不改。导出遍历 continue 边，首选项停止；内部 nextSceneSeed 不当正文或可见预览。

## 统一返回

同一个 result.json 封套同时用于成功、原生失败、输入拒绝、预算耗尽、投递未知与适配错误。正文、选项及原生可见未来预览分开保存。固定开头不计新增正文，允许开头直接停在选项处；原生标题可为 option_key，不由适配器编造中文标题。其它内部产物完整留档，不拼入当前路径。

结构成功与故事质量分开。原生缺少输出时返回空数组和明确状态，不伪造成功。每段文字保留原生指针并回读核对。所有选择保持未执行；未观察到选择状态时为 null，不能写成 false。

## 条件与证据

一份 experiment.v3 配置冻结模型、endpoint、模型控制与预算，拒绝各系统覆盖。实际 HTTP 发送次数包含规划、审核、失败重试和辅助文字调用；未发送的预算拦截不计调用。原生 schema、采样参数和更低输出上限保留并记录。

这是共同限制政策，不是实际等 token 或等金额。未知 usage/费用为 null，SDK 和 HTTP 记录不重复计数。已发送但未确认响应的调用为 delivery_unknown。原生预算兜底不能被算正常完成。

服务停止后才封存，保存完整文件清单、来源锁、可执行代码清单和实际请求。重测用新目录，不覆盖历史版本证据。固定响应 fixture 仅证明工程链路；真实模型实测仍需报告具体案例、版本和范围。当前不声称完整多分支可达性、正式统计或生产账号部署通过。

历史 v2/C1 验收保留在各历史报告。它们曾要求强制前置正文和独立标题，并对 IF 重复映射剧情 instructions；v3 已修正这些接入与验收口径，不能继续用旧结果判断当前版本。
