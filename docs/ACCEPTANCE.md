## 共同输入的实际证据

共同文件：`benchmark/examples/CAMPUS-01/shared_task.txt`，1,939 个 Unicode 字符，5,231 个 UTF-8 字节。

- 公共文本 SHA-256：`af81207f820c2e6e8ea56939e4b4ed313f1810bf089068bfa1853549c440302a`
- 固定开头 SHA-256：`196d04a58ba5bce543e93788e496ae42fdd547d1583d185cda42c3b969159c65`

这两个值分别从公共文件和实际收件文本核验，不是把公共文件的哈希复制到三个日志。三者首个消费任务的模型请求都包含完整共同文本一次，且观察到了后续正文请求。

| 项目 | 实际观察边界 | 同一开头完整存在 | 原生流程 |
| --- | --- | --- | --- |
| IF Line | 原生任务快照 `native_task_snapshot` | 是 | Bible → 大纲 → 章节 → Script IR |
| AI4VisualNovel | 原生需求函数返回值 `native_requirements_reader` | 是 | Designer → Producer → Actor → Writer |
| InfiPlot | 原生 SDK 任务块 `native_sdk_task_block` | 是 | Writer → 原生辅助文字处理 |

InfiPlot 的 SDK 收件不是路由内部字段抓取。后续请求是否保留了开头全文按真实情况记录；使用原生摘要时标为 `cannot_confirm`，不自行认定语义保留，也不重新注入开头。

[判等结果](evidence/common-input-equality.json)与[证据分类索引](EVIDENCE_INDEX.md)可以复核。运行 `python3 tools/verify_evidence.py` 会检查档案哈希并重新读取三套实际收件。

## 已实现与下一步边界

- 已实现：共同任务编译、逐字判等、原生入口接入、实际请求记录、统一预算配置、来源导出、错误保留、源码保护、运行隔离和保存产物恢复。
- 本期输出：首批正文与原生已有的选项。IF Line 当前 Script IR v3 没有玩家选择字段，导出为空并明确记录；不会为了让结果好看而编造选项。AI4VisualNovel 遇到首选择或条件/跳转边界停止导出；InfiPlot 导出首选择之前的原生可见内容。
- 尚未执行：共同真实模型、预算的正式冻结与供应商运行；其示例配置为 `live=false`、模型/预算为空，发送前会拒绝。当前开头是 pilot 候选，其他 29 题未编造开头。
- 不在本期：完整播放器、AA/AB/BA/BB 分支探索、存档分叉、AI 评分、正式统计与完整视听作品。

这份交付提供公平公共输入的可执行基础；完整故事和分支能力的对比，需要另行确定实验执行和评测阶段。
