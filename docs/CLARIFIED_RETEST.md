## 接入修复

| 系统 | 外置适配变化 | 保留的限制 |
| --- | --- | --- |
| IF Line | 新 `provided_prefix_candidates` 模式：原生 Bible、大纲之后，原生人工修订 API 导入固定开头；外置补建结构 checkpoint 和原生空状态，再调用原生候选分支生成。响应丢失时通过精确匹配恢复已有修订。 | 原生候选只有 key、选择后预览、状态变化，没有独立选项标题；预览不计入 `generated.jsonl`。原默认首章模式仍保留。 |
| AI4VisualNovel | 导出沿原生无条件 jump 到首个选择，保留原文物理行号和节点来源；不再提前停在第一个自动跳转。节点数量失败增加准确诊断。 | 不删改原生图、不绕过原生数量校验、不增加原生不存在的生成修复循环；条件控制仍明确停止。 |
| InfiPlot | 首个选择的全部选项保留；增加 Writer 原始选项到原生响应、导出的只读对照记录。 | 不增删选项，不修写标签或 effect，不执行选择。 |

公共输出边界审计新增原生标签来源、数量、停止位置、是否执行选择等检查。语义等价由旁置内容审阅判断；字符串不同不会自动判为语义错误。每次根运行封存自己的 `case.json`，不依赖事后可变的公共案例判断停止规则。

IF Line 的一次性前文导入与公共字段映射是明确的实验接入变化，不是默认原生流程原封不动运行；三者共享外部材料，不宣称内部完整模型消息相同。详见 [公平性边界](FAIRNESS.md)。

## 相同条件与实际结果

本轮每个项目各一次独立根运行，无外置重试择优。真实供应商为 `https://api.deepseek.com`，共同模型 `deepseek-v4-flash`，所有 12 次实际 HTTP 都验证 `thinking: {type: disabled}`。每根运行上限 160 次 HTTP、1,800 秒；每次输出上限 16,384 tokens、完整紧凑请求上限 200,000 Unicode 字符。保留原生更低上限及采样参数。费用不可得，不宣称严格等金额或实际 token 消耗相等。

| 系统 / 运行 | 当前路径新增正文 | 实际结果 | 供应商报告 tokens |
| --- | --- | --- | --- |
| IF Line / `if_line-c1-01` | 0；另有两个未选择预览，共 275 非空白字符 | 6 次 HTTP 完成。原生 A 优先进楼，B 先照顾周遥再向楼内收音机行动，基本对应行动区别；仍缺少选项标题与选择前衔接正文，标记 `unsupported_output_boundary`。 | 19,206 |
| AI4VisualNovel / `ai4visualnovel-c1-01` | 0 | 3 次 HTTP 完成。图为 root＋node1 至 node10，共 11 节点，违反原生要求 12；正文阶段未启动，明确原生失败。 | 10,138 |
| InfiPlot / `infiplot-c1-01` | 21 段、933 非空白字符，两个选项 | 3 次 HTTP 完成。可见正文从楼外开头继续，技术停止边界通过；B 却要求去远处检查收音机，effect 也强调不靠近旧楼，与检查楼内设备的澄清不符。 | 13,151 |

InfiPlot 的错误选项在 Writer 原始响应、原生响应和最终导出中完全相同。此次不是适配器丢失或改写选项。正文中再次响起信号但没有交代周期流逝、选择前有轻微阻拦动作，属于需要复核的时序或行动边界疑点，不直接视为程序已选择 B。

IF Line 预览也不是无瑕疵：B 的信号“还在响”缺少重响交代，新手电等物品引入不充分。内部大纲仍含从图书馆开场的规划；它没有被当作当前已经发生的正文。旁置审阅对候选请求内嵌 JSON 解码后检查 `chapter_tail`，与公共开头逐字相同；通用原始字符串审计中的 `cannot_confirm` 保留，不事后修改封存证据。
