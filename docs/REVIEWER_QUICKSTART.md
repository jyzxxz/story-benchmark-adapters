# 评审者打开与阅读说明

你收到的 `review.zip` 是离线图文故事评阅包。无需安装生成项目、Python、Node 或 Docker，无需账号、API 密钥或网络。IF Line、AI4VisualNovel 和 InfiPlot 的结果使用同一种阅读方式。

## 三步开始阅读

1. **完整解压 ZIP** 到一个普通文件夹。不要只在压缩包预览窗口打开 HTML。
2. 在解压后的文件夹中双击 **`打开故事.html`**（或 `index.html`），用浏览器打开。若默认打开了代码编辑器，请右键选择用浏览器打开。
3. 点击目录中的样本进入故事，按“下一页”“上一页”阅读每页的正文和对应图片。点击“返回全部故事”切换下一份。

如果收到的是完整 `review/` 文件夹，直接从第二步开始。请保留整个文件夹的结构，不能单独移动 HTML 或删除 `samples/`、脚本、图片文件。只有一个样本的独立回放包以 `index.html` 直接进入播放器，可能没有总目录。

## 阅读操作

| 操作 | 用法 |
|---|---|
| 翻页与回看 | 点击“下一页”“上一页” |
| 自动播放 | 点击“自动播放”，可暂停；遇到选择页会自动暂停，阅读后点“下一页”继续 |
| 找到某一页 | 输入页码跳转，或从页面目录选择 |
| 找到某个样本 | 返回全部故事后，用样本编号搜索；总目录也支持按有无正文筛选 |
| 查看实际选择 | 选择页标出当次已经执行的选项；这里展示记录，不重新选择或生成其他路线 |

## 评阅时怎样理解内容

- 开头标注的“公共固定开头”是生成前提供的共同材料。它不计入某个项目新增正文的质量，但后文应与之保持一致。
- 回放展示已经记录的实际路径。“已到统一观察边界”表示本次阅读范围结束，不等于完整故事结局；不要仅因缺少全篇结局而扣分。
- 空正文、生成失败、画面缺失和占位会如实标明。不要用其他样本的内容补齐，也不要把“播放器能打开”当成生成成功。
- 若页面标明“固定响应测试”，该样本用于检查程序，不能作为真实故事质量结果。
- 样本编号用于关联评阅意见。反馈时请同时写明样本编号、页码、具体问题和正文或画面证据。播放器不自动提交或汇总评审意见，请按组织者要求另行记录。

## 八项评测如何分工

人工或 AI 可依据正文、实际画面和配套材料评阅：固定事实与要求、故事连贯性、人物视觉一致性、阅读体验、图文匹配。结构化材料位于每个样本的 `story.json`、`transcript.md` 和 `evaluation/`。

另外三项——等待时间、token 消耗、图片生成数量——由组织者根据生成时的原始记录核对。**不要用自动播放速度估算生成等待时间，也不要用页数或图片文件数代替图片生成数量。** 原始八项指标及匿名样本对应关系由组织者保留，不要求盲评者猜测项目来源。

## 无法打开或图片不显示

先确认完整解压，并保留随包所有文件。正文页若仍提示图片无法读取，请将样本编号、页码和错误提示交给组织者；若页面明确标记原记录缺图，按记录缺失处理。如果只能看到公共开头与停止说明，可能是这次生成没有正文，请保留这份样本的失败记录。

组织者的本地入口定位、旧故事补打包及故障处理见 [完整使用说明](PLAYBACK_REVIEW.md)。
