# 八项指标证据采集对照

原件逐字保存在 `benchmark/source/recording_spec.v0.1.md`。这是 v4 的实现对照，不覆盖原件。对话引用的 `record_templates.json` 未作为实际文件提供；本次字段由外置记录器实现并标注版本 `recording.1`。

| 指标 | 保存内容与定位 | 程序输出的边界 |
|---|---|---|
| M1 固定事实与要求 | `inputs/` 中公共任务、brief、开头、源文件、case、时间解释及 `constraints.json`；实际正文和选择 | 公共原句带出处与字符范围；主要固定事实/知识/条件/选择分类。通用原句拆分仍须内容复核，不编造通过率 |
| M2 连贯性 | `trajectories/main/story.jsonl` 的顺序、说话人、原生 ID、修订、JSON 指针、观察时原文；`native/` 保留状态与原始产物 | 只记录实际路径，公共前文单列；不把原生规划当成已发生事实 |
| M3 人物视觉一致性 | `characters/versions.jsonl`、参考资产、按实际路径排列的 `frame_map.jsonl`、正文和合法变化依据 | 身份映射是候选；未规定的外貌不自造标准；不足两次可比出场可记无法判断 |
| M4 等待时间 | `telemetry/events.jsonl` 的单调时钟、UTC、边界观测名、interaction ID、段落/画面关联 | 同一父记录进程的 `timestamp_observer_id/clock_id` 计算；浏览器自有时间只作原始诊断。离屏、后台、真实桌面分列 |
| M5 阅读体验 | 冻结的实际正文、对白、选项、已执行选择、截止位置及 `evaluation/reading_blind.json` | 盲审包不含项目、模型、成本或内部审核分；不把公共开头计为原创，不按全篇结局评分 |
| M6 图文匹配 | 干净画面与 UI 截图、完整段落覆盖区间、修订、资产图层、人物候选；生成请求/构图用途供私有诊断 | 原生渲染或明确等价确定性合成；裁判看正文、公开要求和实际画面，图片 prompt 不作答案 |
| M7 token | 每个 HTTP 尝试、模型和 native operation、供应商请求 ID、完整 raw usage、请求响应、失败与重试 | 输入/输出/总量仅使用供应商提供值；缓存/推理细分不重复相加；部分覆盖只给已知小计；外部评测另列 |
| M8 图片数 | `images/requests.jsonl`、全部 `outputs.jsonl`、原始文件、变换后 `assets.jsonl`、实际画面引用 | 请求/候选/资产/独立内容/使用/合成分开；同像素独立候选不合并计费；下载失败候选不删除 |

## 关联与验收

正文记录保存 `native_source.file/pointer`，AI4VisualNovel 还保留原始物理行；`native_source_audit.json` 回到原生锚点核对完整原文。`native/observed_text/` 保存截断前观察到的原文本，验证公共句界和累计字符。

`frame_map.jsonl` 将实际显示区间与 `segment_id/revision_id`、`asset_id`、角色候选绑定。资产通过 `output_id` 回到返回候选，再通过 `call_id` 回到真实图像请求；去背景、缩放或重新编码使用 `parent_asset_id`。未知关联明确留空并报告覆盖，不按“长得一样”猜候选归属。

空正文但有图/选项的原生画面也保存，标记 `observed_empty_body=true`；它不会产生伪正文。图片关闭、缺失和占位有各自状态。多个段落共用一张图时保留所有实际映射，不挑最匹配的一句。

每个根运行保存一个主路径，同时保留原生预生成的其他分支和消耗。程序没有把不同路线的正文拼接为一个样本，也没有把公共规划或复用图片按引用次数重复计费。IF Line 的选择对应原生创作路径 promotion，AI4 对应原生 Pygame 选项，InfiPlot 对应原网页 DOM 和 Session 状态变化；这些接口差异公开记录。

结束前停止原生客户端，收集已发送请求终态，生成指标和评审包，再对全部证据文件封存哈希。恢复读取不重发模型请求。比较时原生结局、范围不足、内容失败和采集缺失分开呈现。

## 计时解释

事件的 `observer` 表示观测边界，如 `adapter_backend`、`offscreen_native_dom`。本次公共事件的时间由同一父记录进程采集，`timestamp_observer_id` 与 `clock_id` 一致；只有相同测量时钟才能计算差值。浏览器报告的 `browser_monotonic_ms`、Vue 子进程时钟不能直接与父时钟相减。

后台首正文可用时点可早于生图与播放。AI4 的早期脚本可用事件只在节点确实属于实际路径且有正文时参与首正文时间；IF 按实际访问的 Script IR 修订关联，较早的章节正文只保留为诊断事件。其他预生成文本不能作为首正文。`model_first_chunk` 不参与首正文判定。

根任务时延包括独立环境准备和采集开销，因此是此运行模式下的测量，不是线上服务已有会话的响应时间。选择后延迟通过 interaction ID 对齐，阅读前停顿不计入该延迟。预取成本仍计入根运行；并行模型调用耗时不相加当作等待。

`scheduling_context.json` 及批次 `scheduling/` 保存每次启动的并发、主机平台和任务起止。`latency_scheduling_conditions_identical` 单独比较这些已记录条件；缺记录为 `null`。主机其他工作负载和供应商实际限流仍标为未测，不把它们隐含视为相同。

## 已知与未知

未采集真实桌面用户显示时间时报告 `not_measured/null`。没有供应商实际账单时费用报告 `unavailable/null`，不从 token 或应用内 credits 估算。M1/M2/M3/M5/M6 均为 `not_evaluated`，只准备证据，不用采集测试通过代替质量结论。

约束清单保留原句和主要分类，不为新题目臆造故事事实；适用时点、原生菜单对应 C1/C2、角色视觉身份及合法变化仍须在评审端检查。固定开头的既成事件不能获得生成奖励，后文违背前文仍可记错。评审包同时给出前文、实际正文和选择，避免只凭角色内部状态评分。

密钥、Cookie 和签名 URL 查询参数从证据中脱敏；传给原生客户端的真实响应不受这一脱敏步骤改写。完整私有调用档案与盲审包分开放置，盲审时只导出所需材料。
